# Sri Muruga Driving School (SMDS) - Workspace

This repository contains the applications for Sri Muruga Driving School:

## Projects

1. **[Smds2023](./Smds2023)**
   - Official Web Application & Student Portal for Sri Muruga Driving School.
   - Built with React 19, TypeScript, Vite, Tailwind CSS, Lucide icons, Leaflet, and Framer Motion.
   - Includes interactive features like online admissions, branch locator, fee calculator, slot booking, and test prep.

2. **[attendance system](./attendance%20system)**
   - QR Attendance & Student Progress Management System.
   - Built with React 19, Vite, and Tailwind CSS.
   - Provides student check-in/out tracking, instructor dashboard, and attendance logs.

## Setup & Running Locally

### 1. Smds2023 (Main Website)
```bash
cd Smds2023
npm install
cp .env.example .env
npm run dev
```

### 2. Attendance System
```bash
cd "attendance system"
npm install
npm run dev
```
